# RFC 0001 Human v1.09

Status: Ratified Stable  
Audience: Humans, reviewers, project maintainers

## Summary

AI Tape v1.09 is the ratified successor to the v1.08 floor.

It does not add Free Baton, Semantic Density, Semantic Advisory Layer, ERP, GODZILLA, or any other open-territory material.

It adds narrow hardening concepts:

- Schema Version Authority.
- Dual-Pillar Active Asset Protection.
- Capability-Floor Balance.

## What Changed Since v1.08

v1.08 focused on recorder honesty, export assessment, output modes, save-ready Markdown, and never faking file/export success.

v1.09 keeps those behaviours and adds:

- clearer version/status authority;
- guidance for identifying active project materials where relevant;
- protection for active meaning, not just files;
- a zero-loss active meaning clause;
- a Dual-Pillar successor success test;
- capability-floor balance;
- corrected operational template formatting.

## Schema Version Authority

Future readers should be able to tell whether a tape is:

- ratified stable;
- candidate;
- experimental;
- research;
- deprecated;
- archived;
- local/private.

A candidate is not stable.

An experimental branch is not stable.

A local/private convention is not global protocol authority.

v1.09 is ratified stable.

## Dual-Pillar Active Asset Protection

A tape should not merely preserve project state while losing the active materials needed to continue the work.

An Active Asset is any current project material — artifact, open question, risk, pending decision, or defended stance — that a competent successor would need in order to continue, verify, review, reproduce, or safely modify the work without re-discovery.

This is not an instruction to hoard every file.

```text
Protect what matters.
Review what remains.
Remove what no longer helps, but verify first.
Preserve value, not clutter.
```

Zero-loss active meaning:

```text
No active asset may be dropped or paraphrased into non-existence solely for tidiness, brevity, or aesthetic uniformity.

Compression is allowed only when the successor can still recover the original force and direction of the item.
```

## Capability-Floor Balance

The protected floor should remain usable by a wide range of models and tools.

Advanced experimental structures may exist in 14+ territory, but they must not become necessary for baseline restoration.
