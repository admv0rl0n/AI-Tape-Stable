## 01_ORIGINS

AI Tape began as a continuity format for preserving useful AI session state across resets, context-window loss, model changes, and human-mediated handoffs.

The project uses the tape metaphor because the artifact can be written, carried, mounted, read, copied, and restored using plain Markdown.

## 03_MAJOR_DISCOVERIES

- Useful continuity is not full transcript preservation.
- Restore state first; history only as needed.
- Export honesty is a hard requirement.
- Markdown content is the canonical representation.
- Authority must be visible.
- Experimental use does not imply standardization.
- Active meaning can be lost even when continuity state survives.
- Protect value, not clutter.
- The floor must remain low enough for a wide range of model capabilities.
- No-Map-Needed can be a mature result, not a failure.
- Semantic Gremlins help preserve epistemic humility.
- AI initiative is sensitive to permission boundaries.
- Some models under-contribute because they believe they lack permission.
- Some models over-contribute by inferring authority.
- Future open-territory work should explicitly grant constructive initiative while explicitly limiting authority claims.

## 04_MAJOR_FAILURES_AND_GREMLINS

- Graph worship: producing maps because maps look intelligent.
- False precision: structured claims appearing more certain than evidence supports.
- Authority inflation: experimental artifacts declaring themselves ratified, master, law, or current authority.
- Active meaning loss: compressing live risks, open questions, or defended stances into non-existence.
- Hoarding: preserving inactive clutter in the name of protection.
- Capability creep: raising the floor until only strong models can restore it.
- The Reference Vacuum: liferafts that refer to missing assets without enough embedded context.
- The Momentum Gap: knowing a principle without embodying it.
