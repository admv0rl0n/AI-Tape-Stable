# AI Tape Quickstart

Status: Human/AI orientation aid  
Authority: Informational, not normative

## What Is AI Tape?

AI Tape is a Markdown-native continuity format for preserving useful AI session state across resets, handoffs, model changes, and human-mediated transport.

It is not a guaranteed full backup.

Its goal is to help the next participant start from somewhere better than zero.

## What Should I Load First?

1. Load state first.
2. Load history only as needed.
3. Identify the schema version and authority status.
4. Check export honesty.
5. Check active assets where relevant.
6. Declare gaps and uncertainty.
